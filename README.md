# PDFSPLIT

ברוכים הבאים לPDF SPLIT
תוכנת פיצול PDF זו עלתה לבקשתכם על מנת לפרק קבצים גדולים ליחידות נשלטות שניתן להכניס לLLM כמקורות.

השימוש בתוכנה כמו גם בתוצריה על אחריותכם והיא אינה נועדה לפירטיות גניבת מסמכים, גניבה ספרותית ועוד....
